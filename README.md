## 🌐 **Описание / Description**  

**Русский**  
**Connectivity Logger** – это Android-приложение для мониторинга и записи параметров интернет-подключения. Оно фиксирует силу сигнала, тип сети (Wi-Fi/4G/5G), скорость передачи данных и другие метрики, помогая анализировать качество соединения.  

**English**  
**Connectivity Logger** is an Android app that monitors and logs your internet connection metrics. It tracks signal strength, network type (Wi-Fi/4G/5G), transfer speed, and other parameters to help debug connectivity issues.  

## 📱 **Функции / Features**  
✔ **Логирование параметров** / **Parameter logging**  
   - Уровень сигнала (dBm, RSSI) / Signal strength  
   - Переключения между сетями / Network switching  
   - Скорость загрузки и отдачи / Download/upload speed  

✔ **Визуализация данных** / **Data visualization**  
   - Графики изменений сигнала / Signal history charts  
   - Статистика по сессиям / Connection session stats  

✔ **Экспорт данных** / **Data export**  
   - CSV, JSON для анализа / CSV/JSON for analysis  

## 🎯 **Для кого? / Use Cases**  
- **Тестировщики сети** / Network testers  
- **Разработчики** / Developers (debugging)  
- **Пользователи с нестабильным интернетом** / Users with unstable connections
